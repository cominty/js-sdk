# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/cominty/js-sdk/security/advisories/new).
**Do not open a public issue.**

Include what you found, how to reproduce it, and the SDK version affected. We
will acknowledge the report, keep you updated while we investigate, and credit
you in the advisory unless you would rather we did not.

## Supported versions

Security fixes are released for the latest published version.

## If your API key leaks

An API key in a public issue, a commit, or a client-side bundle should be
treated as compromised. Revoke it at
[platform.cominty.ai/api-keys](https://platform.cominty.ai/api-keys) and create
a new one.
